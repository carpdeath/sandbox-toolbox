# Sandbox Toolbox

A sandbox cheat panel for **Manor Lords**, built on UE4SS.
The goal was to make a fully-featured mod menu for Manor Lords. If you have any ideas on features to add, reach out.
Tested and works on Manor Lords **0.8.117**, latest as of November 2026. Some features might (or might not) work on other versions.

## Installation instructions

Manual:

1. Install UE4SS (either [ML-UE4SS](https://www.nexusmods.com/manorlords/mods/229) or [the regular one](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest))
2. Extract the mod zip contents into `<Manor Lords>/ManorLords/Binaries/Win64/ue4ss/Mods/`
3. Launch the game, load into a save and press **F6**

Or use your mod manager of choice.

## Main features

- Add any resource
- Spawn families
- Add influence, treasury and regional wealth
- Big storage: raise the storage cap
- Instant construction
- Spawn bandit camps and raiders
- Unlock the militia cap
- Immortal units
- OP units: boosted attack, ranged damage and armor piercing
- Infinite stamina and morale for your troops

## Requirements

- UE4SS
